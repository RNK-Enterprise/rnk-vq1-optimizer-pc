# PC mesh changelog

## 2026-10-08

- Removed all non-PC host adapters, UI files, gateway relay code, and related
  tests from the public PC release.
- Kept the native authority, browser-owned local media host, and local typed
  mesh as the supported surfaces.
- Added strict coverage collection for the entire PC runtime tree.

## 2026-10-07

- Scoped the public inventory to 38 engines, 152 turbos, and 190 paired
  libraries.
- Added lazy, trigger-validated engine execution to the local PC mesh.

## 2026-10-05

- Clarified the separation between the browser-owned media host and native
  whole-PC agent.
